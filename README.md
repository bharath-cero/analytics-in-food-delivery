# Analytics in Food Delivery

A short educational talk for university students studying analytics. The deck
introduces the operating challenges of a three-sided food-delivery marketplace,
explains the role of Analytics Engineering and semantic context, and closes with
practical advice for maximizing early-career learning.

## Present

Open `index.html` in a browser or use the public GitHub Pages site.

| Key | Action |
| --- | --- |
| Right arrow or space | Next reveal or slide |
| Left arrow | Previous reveal or slide |
| Up or down arrow | Previous or next slide |
| `O` | Slide overview |
| `N` | Speaker notes |
| `T` | Timer |
| `F` | Full screen |

## Build

```bash
python3 build.py
```

The generated `index.html` is self-contained apart from web fonts and remains
usable with system fonts if the network is unavailable.
